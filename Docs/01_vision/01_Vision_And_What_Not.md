# SYNAPSE Vision and What-Not

## Vision

SYNAPSE is an AI-native Personal Investment Research System.

It is not an auto-trading bot. It is not a stock recommendation feed. It is a research memory infrastructure that helps individual investors build, track, and evolve their investment research over time.

Core positioning: **Research Memory Infrastructure** / **Personal Cognitive Infrastructure for investing**.

## Core Value

SYNAPSE should help users:

1. Generate a daily research queue of stocks worth investigating (not stock recommendations).
2. Monitor positions through the lens of active research theses (not just P&L).
3. Run reproducible factor research experiments.
4. Accumulate research memory that captures cognitive state over time ("freeze cognition").
5. Use AI to accelerate research, not replace investment judgment.
6. Output "worth researching" — never "should buy."

## 4 Core Features

| Feature | Positioning |
|---------|------------|
| Daily Watchlist | Research Queue, not Stock Recommendation Feed |
| Position Monitor | Active Thesis Tracker, research-state-first (not red/green P&L) |
| Factor Research | P0 completed (124 tests, governance-first) |
| Research Memory | Freeze cognitive state, not a trading log |

## Design Principles

- **Research Queue, not Stock Recommendation**: "下一件值得研究什么" not "下一只该买什么"
- **Cognitive Freezing**: Record the reasoning behind decisions, not just outcomes
- **Anti-同花顺化**: No red/green center, no hot lists, no AI authority, no dopamine economy
- **Thesis-driven**: All research objects link through Thesis, not just ticker
- **Slow Research over Fast Stimulation**: Every feature should ask "does this strengthen research or刺激 trading?"

## What SYNAPSE Is

SYNAPSE is:

- AI-native Personal Investment Research System
- Research Memory Infrastructure
- Thesis-driven research workflow system
- Experiment governance system
- Factor research assistant
- Active thesis tracker (position monitor)
- Daily research queue generator
- Cognitive infrastructure for investing

## What SYNAPSE Is Not

SYNAPSE is not:

- An auto-trading bot (will come later, not now)
- An automatic money machine
- A stock recommendation tool
- A hot list / leaderboard / social feed
- A generic AutoGPT-style autonomous agent
- A low-code strategy drag-and-drop platform
- A universal alpha discovery machine
- A high-frequency trading kernel
- A brokerage order-routing system
- A replacement for human investment judgment
- An information entertainment platform (dopamine economy)

## Current Phase What-Not

P0-P2 does not include:

- Real-money trading (architecture reserves extension points)
- Broker integration
- Ultra-low-latency execution
- HFT / market making
- Public SaaS multi-tenant deployment
- Production compliance workflow
