# Review Checklist

## Product Review

- Is the user clear?
- Is the current alpha domain clear?
- Is P0 scope clear?
- Are out-of-scope items explicit?

## Architecture Review

- Does the change violate research-first positioning?
- Does it introduce real trading?
- Does it couple the system to an external project too early?
- Does it mix platform and research methodology responsibilities?

## Research Governance Review

- Are data timestamps explicit?
- Is leakage risk considered?
- Are failed experiments preserved?
- Are transaction costs recorded?
- Are assumptions visible?

## AI Coding Review

- Did AI add hidden behavior?
- Did AI silently change schemas?
- Did AI create fake static functionality?
- Did AI bypass governance?
- Did AI introduce future-stage features?
